# PC TECH STORE — متجر أجهزة كمبيوتر ولابتوب

موقع متجر أجهزة كمبيوتر ولابتوب، عربي بالكامل (RTL)، مبني بـ HTML و CSS و JavaScript بس.
مفيش سيرفر، مفيش قاعدة بيانات، مفيش Node — يعني تقدر تفتحه بدبل كليك وتشتغل.

> الاسم والتليفون والواتساب والمنتجات كلها بتتغيّر من ملف واحد:
> `assets/js/data.js`

---

## ١) إزاي تفتح الموقع

روح على فولدر المشروع واضغط دبل كليك على **`index.html`**.

- الموقع بيشتغل أوفلاين بالكامل من غير إنترنت (الصور كلها محلية في `assets/img/`).
- بس خط Cairo بيتحمّل من Google Fonts؛ لو مفيش نت الموقع هيفضل شغال بخط النظام (Segoe UI / Tahoma).
- لو حابب تشغّله على سيرفر محلي:
  ```bash
  python -m http.server 8000
  ```
  وبعدين افتح `http://localhost:8000`.

### الصفحات

| الصفحة | الملف | إيه اللي فيها |
|---|---|---|
| الرئيسية | `index.html` | هيرو، الأقسام، منتجات مميزة، عرض الأسبوع، وصل حديثًا، ماركات، تقييمات، أسئلة شائعة |
| المتجر | `shop.html` | كل المنتجات + فلتر (قسم / حالة / ماركة / سعر / عروض) + ترتيب |
| صفحة المنتج | `product.html?id=...` | معرض صور، سعر، كمية، إضافة للسلة، طلب واتساب، مواصفات، منتجات مشابهة |
| البحث | `search.html?q=...` | نتائج البحث + ترتيب + كلمات شائعة |

## ٢) تغيير الاسم والتليفون والواتساب

افتح `assets/js/data.js` وغيّر الجزء ده في أول الملف:

```js
window.SHOP = {
  brand: {
    name: "PC TECH STORE",        // الاسم اللي بيظهر في الهيدر والفوتر
    nameAr: "PC TECH STORE",      // الاسم بالعربي في رسايل الواتساب ولوحة الموبايل
    kicker: "لابتوب وأجهزة كمبيوتر",
    logo: "assets/img/logo.jpg",  // صورة اللوجو (سيبه فاضي لو عايز الحروف)
    logoText: "TP",               // الحروف اللي جوه مربع اللوجو لو مفيش صورة
    address: "العصافرة عبد الناصر خلف بنك ابو ظبي",
    email: "hello@pctechstore.eg",
    phoneDisplay: "01224802782",  // اللي بيتعرض للزائر
    phone: "+201224802782",       // لينك الاتصال
    whatsapp: "201224802782",     // ⚠️ من غير + ومن غير 0 في الأول
    hours: "كل يوم من ١٠ الصبح لـ ١٠ بالليل",
    mapUrl: "",                    // لينك جوجل مابس (سيبه فاضي لو مش عايزه)
    social: [
      { name: "فيسبوك", icon: "f", url: "https://facebook.com/..." },
      { name: "إنستجرام", icon: "◎", url: "https://instagram.com/..." },
      { name: "تيك توك", icon: "♪", url: "https://tiktok.com/@..." }
    ]
  },
  ...
};
```

**مهم:** `whatsapp` لازم يكون بالصيغة الدولية من غير علامة `+` ومن غير الصفر في الأول.
مثال: `01001234567` يتكتب `201001234567`.

نفس الرقم ده هو اللي بيتبني عليه زرار «اطلب على واتساب» وكل رسايل السلة.

### تغيير اللوجو

اللوجو حاليًا صورة في `assets/img/logo.jpg` ومربوطة من `brand.logo` في `data.js`، وبيرسمها `main.js` في الهيدر والفوتر وقائمة الموبايل.

لو عندك صورة لوجو تانية:

1. استبدل `assets/img/logo.jpg` بصورتك (مربّعة أفضل حاجة، 400×400 أو أكبر).
2. أو غيّر المسار في `data.js`:
   ```js
   logo: "assets/img/logo.png",
   ```
3. لو مسحت `logo` خالص، الموقع هيرجع للحروف النصية من `logoText`.

## ٣) إضافة منتجات

كل المنتجات في `assets/js/data.js` جوه `window.PRODUCTS = [ ... ]`.
انسخ أي منتج موجود وغيّر القيم:

```js
{
  id: "dell-latitude-7420",        // ⚠️ لازم يكون فريد — هو اللي بيتبني عليه لينك المنتج
  name: "Dell Latitude 7420",
  brand: "Dell",
  category: "laptops",             // لازم يطابق id من SITE.categories
  condition: "used",               // "new" أو "used"
  price: 14500,
  oldPrice: 16500,                 // اختياري — لو موجود بيظهر الخصم والسعر القديم
  image: "assets/img/laptop-dell-xps.jpg",
  gallery: [                       // صور صفحة المنتج (الأولى هي الرئيسية)
    "assets/img/laptop-dell-xps.jpg"
  ],
  badge: "الأكثر مبيعاً",           // شارة صغيرة على الكارت — اختيارية
  rating: 4.8,                     // اختياري
  reviews: 42,                     // اختياري
  stock: true,                     // true = متوفر / false = خلص
  featured: true,                  // يظهر في «منتجات مميزة» بالرئيسية
  tags: ["لابتوب", "dell", "i7"],  // بتستخدمها خانة البحث
  short: "Core i7 · 16GB RAM · SSD 512GB",
  specs: {
    "المعالج": "Intel Core i7-1185G7",
    "الرام": "16GB DDR4",
    "التخزين": "SSD 512GB"
  },
  desc: "وصف تفصيلي بيظهر في تاب «الوصف» بصفحة المنتج."
}
```

قواعد سريعة:

- `id` مختلف لكل منتج، وبالإنجليزي من غير مسافات (استخدم `-`).
- `category` لازم تكون واحدة من: `laptops`, `desktops`, `gaming`, `gpus`, `monitors`, `storage`, `ram`.
- `price` رقم من غير فواصل ولا علامة جنيه.
- `oldPrice` أكبر من `price` علشان يظهر الخصم. لو مش عايز خصم، امسح السطر خالص.
- السعر بالجنيه؛ العملة نفسها بتتغيّر من `SITE.currency`.
- المنتجات الجديدة (`condition: "new"`) أو اللي عليها شارة `"جديد الوصول"` بتظهر في «وصل حديثًا».

### عرض الأسبوع

العرض الكبير اللي في الرئيسية مش منتج عادي — ليه إعداد لوحده في `SITE.deal`:

```js
deal: {
  kicker: "عرض الأسبوع",
  title: "تجميعة جيمينج كاملة",
  text: "كيسة + شاشة ٢٤ + كيبورد وماوس...",
  price: 21500,
  oldPrice: 24900,
  image: "assets/img/cat-gaming.jpg",
  cta: { label: "اطلب التجميعة", href: "product.html?id=gaming-ryzen-5" }
}
```

خلّي `cta.href` بيوّدي لصفحة المنتج الصح.

### إضافة قسم جديد

في `assets/js/data.js` جوه `SITE.categories`:

```js
{ id: "printers", name: "طابعات", desc: "ليزر وإنك جيت", image: "assets/img/cat-printer.jpg" }
```

وبعدين استخدم `category: "printers"` في المنتجات. القسم هيظهر أوتوماتيك في الرئيسية وفي فلتر المتجر.

### الصور

- حط الصور في `assets/img/`.
- استخدم أسماء إنجليزي من غير مسافات: `laptop-hp-840.jpg`.
- مقاس مناسب: **مربع 800×800** بخلفية بيضا، وحجم أقل من 200KB للصورة.
- الصور الحالية صور منتجات حقيقية من متجر مرجعي، ومسؤولية حقوق استخدامها على صاحب المتجر. استبدلها بصور منتجاتك الفعلية قبل النشر.
- صور الأقسام (`cat-*.jpg`) بتظهر في كروت الأقسام بالرئيسية، ومقاسها المناسب **أفقي 1200×800**.
- كل صورة قسم بتفتح `shop.html?cat=<id>` — يعني أي منتج بياخد نفس `id` القسم هيظهر تلقائي في الصفحة دي.

## ٤) تغيير الألوان والخط

كل التصميم في `assets/css/styles.css`، وأول الملف فيه المتغيّرات:

```css
:root {
  --ink: #0a1526;        /* لون النص الأساسي */
  --brand: #1f5eff;      /* اللون الأساسي (الأزرار واللينكات) */
  --brand-dark: #1444c9; /* نسخة غامقة للـ hover */
  --accent: #f97316;     /* لون التمييز (الخصومات) */
  --paper: #ffffff;      /* خلفية الكروت */
  --paper-2: #f4f7fc;    /* خلفية الصفحة */
  --line: #e1e8f4;       /* لون الحدود */
  --muted: #5c6a82;      /* نص ثانوي */
  --radius: 18px;        /* استدارة الزوايا */
  --font: "Cairo", "Segoe UI", Tahoma, sans-serif;
}
```

غيّر `--brand` و `--accent` (وكمان `--brand-dark` معاهم) وهيتبدّلوا في الموقع كله.

الخط: `Cairo` من Google Fonts، ومربوط في أول `styles.css` وفي وسم `<link>` بكل صفحة.
لو عايز خط تاني، غيّره في الاتنين.

## ٥) السلة والطلب — إزاي بتشتغل

مفيش دفع أونلاين ومفيش سيرفر:

1. الزائر يضيف منتجات → بتتخزن في `localStorage` باسم `techpoint_cart_v1` (اسم المفتاح في المتصفح، مش اسم المتجر).
2. يفتح السلة من زرار الهيدر.
3. يضغط «إتمام الطلب على واتساب» → بتفتح محادثة واتساب فيها رسالة جاهزة فيها المنتجات والكميات والإجمالي.

يعني الطلب بيوصلك على واتساب، وإنت بتأكّد مع العميل وتحدّد الشحن.

> لو عايز متجر بدفع أونلاين فعلي، ده يحتاج backend وبوابة دفع (Paymob / Fawry).
> الموقع الحالي واجهة عرض + طلب واتساب.


1. اعمل repository وارفع الملفات.
2. Settings → Pages → Branch: `main` / root.
3. الموقع هيبقى على `https://username.github.io/repo`.

## ٧) شكل المشروع

```
east-shop/
├── index.html          الصفحة الرئيسية
├── shop.html           المتجر + الفلاتر
├── product.html        صفحة المنتج (بتتبني بالـ JS)
├── search.html         البحث
├── README.md
└── assets/
    ├── css/
    │   └── styles.css  كل التصميم
    ├── js/
    │   ├── data.js     ⭐ كل البيانات (عدّل هنا)
    │   └── main.js     المنطق: الرندر، السلة، الفلاتر، البحث
    └── img/            صور المنتجات والأقسام
```

`data.js` بيتحمّل قبل `main.js` في كل صفحة، وكل الاتنين بـ `defer`.

## ٨) حاجات لازم تعرفها

- **مفيش backend:** مفيش تسجيل مستخدمين، مفيش مخزون بيتحدّث لوحده، مفيش لوحة تحكم. أي تعديل في المنتجات = تعديل في `data.js`.
- **السلة محلية:** لو الزائر مسح بيانات المتصفح، السلة بتتمسح. ده طبيعي في المواقع من غير حساب.
- **الصور التجريبية:** مستخدمة مؤقتًا من موقع مرجعي للتشغيل والعرض بس — متستخدمهاش في النشر النهائي.
- **الخط:** محتاج إنترنت أول مرة، وبعدها المتصفح بيكاشه.
